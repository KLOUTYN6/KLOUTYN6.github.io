RedmiCraft PC - Minecraft Java 26.3 server manager

Windows 10/11 x64
Java 25 or newer

Quick start:
1. Install Microsoft OpenJDK 25 if Java is not already installed.
2. Run RedmiCraftPC.exe.
3. Open SETTINGS and choose RAM, port, player limit, world and performance settings.
4. Press SETUP and confirm that you accepted the Minecraft EULA.
5. Press START.
6. For different Wi-Fi networks, install Tailscale on both PCs and use the Tailscale address shown by the app.

Features:
- Official Minecraft Java 26.3 server download from Mojang version metadata.
- Start / Stop / Restart.
- Live server console with command input.
- RAM and garbage-collector settings.
- Port, player limit, difficulty, gamemode, view/simulation distance.
- PvP, command blocks, commands, whitelist.
- Optional offline authentication for a trusted private server.
- World backup.
- LAN IP and Tailscale IP detection.
- Windows Firewall helper.

Offline authentication warning:
This disables Mojang account verification for the server. Keep it on a trusted private network because player names can be impersonated.
